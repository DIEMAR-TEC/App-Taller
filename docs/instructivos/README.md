# Instructivos

Una hoja A4 cada uno, para imprimir o mandar por WhatsApp.

| Archivo | Para quién |
|---|---|
| `instructivo-taller.pdf` / `.png` | Taller: handheld y celular (escanear la unidad, gomería, stock) |
| `instructivo-choferes.pdf` / `.png` | Choferes: informar una falla desde el celular |

Las fuentes son `taller.html`, `choferes.html` y `estilo.css`. Las
pantallas de `img/` son capturas de `handheld.html` y `choferes/` con datos
de ejemplo; `operario.svg` y `chofer.svg` llevan el QR real de una unidad.
Para regenerar el PDF: abrir el HTML en Chrome e imprimir en A4 sin
márgenes, con gráficos de fondo.
